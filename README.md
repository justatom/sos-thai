# STORY OF SEASONS: Friends of Mineral Town — ม็อดแปลภาษาไทย

ม็อดแปลภาษาไทย (แฟนเมด ไม่เป็นทางการ) สำหรับ **STORY OF SEASONS: Friends of Mineral Town** เวอร์ชัน PC ใช้ได้ทั้ง **Steam** และ **Epic Games Store**

- แปลครบทั้งเกม: เมนู ไอเทม ร้านค้า บทสอนเล่น บทสนทนาชาวเมือง อีเวนต์จีบ/แต่งงาน รายการทีวี หนังสือ (ข้อความไทยราว 19,000 ประโยค)
- สำนวนนิทานเด็กสไตล์ญี่ปุ่น อ่านง่าย น่ารัก ไม่ใช้ ครับ/ค่ะ
- ชื่อตัวละคร/สถานที่ทับศัพท์เป็นไทย ดูคำแปลทั้งหมดได้ที่ [`docs/SoS_FoMT_Thai_Glossary.docx`](docs/SoS_FoMT_Thai_Glossary.docx)
- ฟอนต์ไทย **Noto Sans Thai SemiBold** ใส่ลงในฟอนต์ของเกมทุกตัว ย่อขนาดให้พอดีระยะบรรทัด สระและวรรณยุกต์ไม่ชนกัน

> **repo นี้ไม่มีไฟล์ของเกมอยู่เลย** ตัวติดตั้งจะสร้างม็อดจากไฟล์เกมที่อยู่ในเครื่องของคุณเอง คุณจึงต้องมีเกมแท้ที่ซื้อจาก Steam หรือ Epic

## 2. ติดตั้งบน Steam

### ขั้นที่ 1 — หาโฟลเดอร์เกม
1. เปิด Steam → **Library (คลัง)**
2. คลิกขวาที่ **STORY OF SEASONS: Friends of Mineral Town** → **Manage (จัดการ)** → **Browse local files (เรียกดูไฟล์ในเครื่อง)**
3. หน้าต่างที่เปิดขึ้นคือ**โฟลเดอร์เกม** ข้างในต้องมีไฟล์ชื่อ `disc` (ขนาดราว 1 GB) และ `STORY OF SEASONS Friends of Mineral Town.exe`

   ปกติจะอยู่ที่
   `C:\Program Files (x86)\Steam\steamapps\common\STORY OF SEASONS Friends of Mineral Town`
   ถ้าย้าย Steam Library ไปไดรฟ์อื่น จะอยู่ที่ `<ไดรฟ์>:\...\steamapps\common\STORY OF SEASONS Friends of Mineral Town`

### ขั้นที่ 2 — วาง toolkit
1. แตกไฟล์ toolkit ที่ดาวน์โหลดมา จะได้โฟลเดอร์ชื่อขึ้นต้นด้วย `sos-fomt_disc-toolkit` (เช่น `sos-fomt_disc-toolkit_1-1-1`)
2. **ย้ายโฟลเดอร์นั้นไปไว้ในโฟลเดอร์เกม** (แนะนำ ตัวติดตั้งจะหาเจอเอง)
   ถ้าไดรฟ์เกมพื้นที่ไม่พอ จะวาง toolkit ไว้ที่อื่นก็ได้ ตัวติดตั้งจะถามตำแหน่งตอนรัน

   ```
   STORY OF SEASONS Friends of Mineral Town\
   ├─ disc
   ├─ STORY OF SEASONS Friends of Mineral Town.exe
   └─ sos-fomt_disc-toolkit_1-1-1\
      ├─ unpack-encrypted-disc.bat
      ├─ extract-assets.bat
      ├─ full-rebuild.bat
      └─ utils\
   ```

### ขั้นที่ 3 — รันตัวติดตั้ง
1. ปิดเกมให้เรียบร้อย
2. เข้าไปในโฟลเดอร์ม็อดที่แตกไว้ ดับเบิลคลิก **`install-thai.bat`**
   - ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway**
   - ถ้าเกมอยู่ใน `C:\Program Files...` แล้วขึ้นว่า copy ไม่ได้ / Access denied ให้คลิกขวาที่ `install-thai.bat` → **Run as administrator**
3. ถ้าตัวติดตั้งหาโฟลเดอร์เกมหรือ toolkit ไม่เจอ จะถาม ให้**ลากโฟลเดอร์นั้นมาวางในหน้าต่างดำ** แล้วกด Enter
4. รอจนขึ้น `Done!` (ช่วงที่นานที่สุดคือ encode ฟอนต์และบีบอัดไฟล์)

ตัวติดตั้งทำสิ่งเหล่านี้ให้อัตโนมัติ:
- สำรองไฟล์เกมต้นฉบับเป็น `disc.original` (ครั้งแรกครั้งเดียว)
- ดึงออกมาเฉพาะ 2 ไฟล์ที่ม็อดต้องแก้ (ข้อความภาษาอังกฤษ US และฟอนต์) ไม่ต้องแตกไฟล์ทั้งเกม
- ใส่ข้อความไทยและฟอนต์ไทย แล้วตรวจว่าบีบอัดกลับได้ข้อมูลถูกต้อง
- สร้างไฟล์ `disc` ใหม่ โดยอีก 879 ไฟล์คัดลอกจากต้นฉบับแบบไบต์ต่อไบต์ ไม่มีไฟล์อื่นถูกแตะเลย แล้ววางทับในโฟลเดอร์เกม

ถ้ามีไฟล์ `__disc-in\disc` (ต้นฉบับ) อยู่ในโฟลเดอร์ toolkit แล้ว และยังไม่มี `disc.original` ตัวติดตั้งจะใช้ไฟล์นั้นเป็นต้นฉบับ

### ขั้นที่ 4 — เข้าเกม
เปิดเกมจาก Steam ตามปกติ แล้วตั้งภาษาเป็น **English** (ดู[หัวข้อ 4](#4-ตั้งภาษาในเกม))

> ⚠️ อย่ากด **Verify integrity of game files** ใน Steam ระหว่างที่ใช้ม็อด เพราะ Steam จะเขียนไฟล์ `disc` ภาษาอังกฤษทับ ถ้าเผลอกดไปแล้ว ให้รัน `install-thai.bat` ใหม่

## 3. ติดตั้งบน Epic Games Store

ขั้นตอนเหมือน Steam ต่างกันแค่วิธีหาโฟลเดอร์เกม

### ขั้นที่ 1 — หาโฟลเดอร์เกม
1. เปิด **Epic Games Launcher** → **Library (คลัง)**
2. ที่การ์ดเกม **STORY OF SEASONS: Friends of Mineral Town** กดปุ่ม **⋯ (สามจุด)** → **Manage (จัดการ)**
3. ที่บรรทัด **Installation** กด**ไอคอนโฟลเดอร์** จะเปิดโฟลเดอร์เกมขึ้นมา ข้างในต้องมีไฟล์ชื่อ `disc` (ราว 1 GB)

   ปกติจะอยู่ใต้ `C:\Program Files\Epic Games\` ชื่อโฟลเดอร์ย่อยอาจไม่มีเว้นวรรค เช่น `STORYOFSEASONSFriendsofMineralTown` ให้ใช้ตำแหน่งจริงที่ Launcher เปิดให้

### ขั้นที่ 2–4
ทำเหมือน [Steam ขั้นที่ 2–4](#ขั้นที่-2--วาง-toolkit) ทุกอย่าง:
1. วางโฟลเดอร์ toolkit ไว้ในโฟลเดอร์เกม (หรือที่อื่นก็ได้)
2. ปิดเกมและปิด Epic Games Launcher (กันไม่ให้ Launcher ล็อกไฟล์ระหว่างติดตั้ง)
3. ดับเบิลคลิก `install-thai.bat` (ถ้าเกมอยู่ใน `C:\Program Files\Epic Games\` ส่วนใหญ่ต้องคลิกขวา → **Run as administrator**) ถ้าตัวติดตั้งถาม ให้ลากโฟลเดอร์เกมมาวางแล้วกด Enter
4. เปิดเกมจาก Epic แล้วตั้งภาษาเป็น **English**

> ⚠️ อย่ากด **Verify** ใน Epic ระหว่างใช้ม็อด เพราะ Epic จะเขียนไฟล์ `disc` ต้นฉบับทับ ถ้ากดไปแล้วให้รัน `install-thai.bat` ใหม่

> ℹ️ ม็อดนี้ทดสอบบนเวอร์ชัน Steam ส่วนเวอร์ชัน Epic เป็นเกมเดียวกันและใช้ไฟล์ `disc` แบบเดียวกัน จึงติดตั้งด้วยวิธีเดียวกันได้ ถ้าเจอปัญหาบน Epic ช่วยแจ้งใน [Issues](../../issues) ด้วย

## 4. ตั้งภาษาในเกม

ม็อดนี้แทนที่**ข้อความภาษาอังกฤษ**ของเกมด้วยภาษาไทย จึงต้องตั้งภาษาของเกมเป็น **English**
- ถ้าเดิมเล่นภาษาอังกฤษอยู่แล้ว ไม่ต้องทำอะไรเพิ่ม เข้าเกมก็เห็นภาษาไทยเลย
- ถ้าเคยเปลี่ยนเป็นภาษาอื่น ให้เปลี่ยนกลับเป็น **English** ในเมนูตั้งค่าของเกม (Options / Settings) หรือในหน้าต่าง Launcher ของเกมที่ขึ้นก่อนเข้าเกม

## 5. ถอนการติดตั้ง / กลับเป็นภาษาอังกฤษ

เลือกได้ 2 วิธี:
- **วิธีที่ 1:** ดับเบิลคลิก **`uninstall-thai.bat`** ตัวถอนการติดตั้งจะคัดลอก `disc.original` กลับไปเป็น `disc`
- **วิธีที่ 2:**
  - Steam: คลิกขวาที่เกม → Properties → Installed Files → **Verify integrity of game files**
  - Epic: ⋯ → Manage → **Verify**

ไฟล์เซฟไม่ได้ผูกกับภาษา ถอนม็อดแล้วเล่นเซฟเดิมต่อได้

## 6. เมื่อเกมอัปเดต

ถ้าเกมได้รับอัปเดต (ไฟล์ `disc` ถูกเปลี่ยน) ให้ทำตามนี้:
1. ลบไฟล์ `disc.original` เดิมในโฟลเดอร์เกม (เป็นของเวอร์ชันเก่า)
2. ให้ Steam/Epic **Verify** ไฟล์เกม เพื่อให้ได้ `disc` เวอร์ชันใหม่ที่เป็นภาษาอังกฤษล้วน
3. รัน `install-thai.bat` ใหม่ (ระบบจะสำรอง `disc.original` ของเวอร์ชันใหม่ให้เอง)

## 7. แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| `Python 3 was not found` | ติดตั้ง Python จาก python.org และติ๊ก **Add python.exe to PATH** แล้วรันใหม่ (ถ้าติดตั้งแล้วแต่ยังขึ้น ให้รีสตาร์ทเครื่อง) |
| `Could not install Pillow` | เปิด Command Prompt พิมพ์ `py -3 -m pip install pillow` แล้วรันตัวติดตั้งใหม่ |
| `...already contains Thai` / `...fonts already contain Thai` | `disc.original` ที่สำรองไว้ไม่ใช่ไฟล์ต้นฉบับ (ถูกม็อดไปแล้ว) ให้ลบ `disc.original` → Verify ไฟล์เกมใน Steam/Epic → รัน `install-thai.bat` ใหม่ |
| `Could not read ...` / `Missing toolkit file` | `disc.original` อาจเสียหรือเป็นไฟล์ที่ถูกม็อดอื่นแก้มา ทำแบบแถวบน หรือดูว่าโฟลเดอร์ toolkit ครบ (มี `utils\7zip`, `utils\quickbms`, `utils\texconv.exe`, `utils\d`) |
| Copy ไม่ได้ / Access denied | คลิกขวา `install-thai.bat` → **Run as administrator** และปิดเกม/Launcher ก่อน |
| เข้าเกมแล้วยังเป็นภาษาอังกฤษ | ตรวจว่าตั้งภาษาเกมเป็น English และไม่ได้เผลอกด Verify หลังติดตั้ง |
| เข้าเกมแล้วเห็นช่องว่าง/สี่เหลี่ยมแทนตัวอักษร | ติดตั้งไม่ครบ (มักเพราะ encode ฟอนต์ถูกขัดจังหวะ) ให้รัน `install-thai.bat` ใหม่ |
| แอนตี้ไวรัสบล็อก `.exe` ใน toolkit | toolkit ใช้ 7-Zip, QuickBMS และ texconv (ของ Microsoft) ซึ่งเป็นเครื่องมือมาตรฐาน ให้อนุญาตโฟลเดอร์ toolkit แล้วรันใหม่ |

## 8. ติดตั้งเองทีละขั้น (สำหรับผู้ใช้ขั้นสูง)

ถ้าไม่อยากใช้ `install-thai.bat` ให้รันตัวสร้าง disc เอง:

```
py -3 -m pip install pillow
py -3 "<โฟลเดอร์ม็อด>\tools\build_disc.py" --toolkit "<โฟลเดอร์ toolkit>" --original "<disc ต้นฉบับ>" --out "<โฟลเดอร์เกม>\disc"
```

`build_disc.py` ทำแบบนี้:
1. ใช้ 7za ของ toolkit ดึงเฉพาะ `resource\message\ichigo_message_all_US.lzs` และ `resource\ui\font_data.lzs` ออกจาก disc ต้นฉบับ
2. ใช้ QuickBMS (สคริปต์เดียวกับ toolkit) คลายการบีบอัด แล้วแตกไฟล์รวมด้านใน
3. ใส่ข้อความไทยและฟอนต์ไทย (`install_thai.py` ใช้ texconv encode ฟอนต์ในขั้นเดียวกัน)
4. ประกอบไฟล์รวมกลับแบบเรียงตามต้นฉบับ (จัดแนว 128 ไบต์) แล้วบีบอัดด้วย QuickBMS และคลายกลับมาเทียบว่าตรงกันทุกไบต์
5. เขียน disc ใหม่ โดยคัดลอกไฟล์อื่นจากต้นฉบับแบบดิบ (ยังเข้ารหัสอยู่เหมือนเดิม) แล้วตรวจซ้ำก่อนวางทับ

> อย่าใช้ `full-rebuild.bat` สร้าง disc ของม็อดนี้ เพราะจะบีบอัดไฟล์ใหม่ทั้งเกม (อนิเมชันตัวละคร แผนที่ ฯลฯ) ไม่ใช่แค่ไฟล์ที่ม็อดแก้

`install_thai.py` จะไม่ยอมทำงานกับไฟล์ที่มีภาษาไทยอยู่แล้ว (กันการใส่ฟอนต์ซ้ำ) ต้องใช้ `disc` ต้นฉบับเสมอ

## 9. แจ้งคำแปลผิด / ร่วมพัฒนา

- เปิด [Issue](../../issues) แนบ**ภาพหน้าจอ**หรือ**ข้อความไทยที่เห็นในเกม** และคำที่อยากให้เป็น
- รายการชื่อและศัพท์ทั้งหมดอยู่ที่ [`docs/`](docs/) ถ้าเป็นศัพท์ในรายการ แก้ที่เดียวจะเปลี่ยนทั้งเกม

โครงสร้าง repo:
```
install-thai.bat            ตัวติดตั้งอัตโนมัติ
uninstall-thai.bat          คืนไฟล์เกมต้นฉบับ
tools/install_thai.py       ตัวสร้างม็อด (ใส่ข้อความ + ฟอนต์ลงไฟล์ที่แตกจากเกม)
translation/th.json         คำแปลทั้งหมด  { "ไฟล์ข้อความ.bin": { "ลำดับ": "ข้อความไทย" } }
fontkit/                    ฟอนต์ Noto Sans Thai + ชุด glyph ไทยหลายขนาด (em23–em33)
docs/                       รายการคำแปล (Word), กลอสซารี, คู่มือสำนวนแปล
```
